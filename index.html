Leksehjelp

Legg inn pensum, så kan du snakke om det, ta quiz, høre foredrag og få sammendrag – alltid basert på ditt stoff.

Appen virker best med en gratis Gemini-nøkkel (gir samtale, ekte quiz, foredrag og faktasjekk).

      Sammenligner påstandene i stoffet ditt med Wikipedia og sier fra hvis noe ikke stemmer. Appen bruker likevel alltid ditt stoff i quiz og foredrag.

      Innstillinger

      Lag en gratis nøkkel på aistudio.google.com/apikey (logg inn med Google-konto, trykk «Create API key»). Nøkkelen lagres bare på denne telefonen. Merk: på gratisnivået kan Google bruke det du sender til å forbedre tjenestene sine – ikke legg inn personopplysninger.

      Installer på iPhone

      1. Åpne siden i Safari.
      2. Trykk på Del-knappen (firkant med pil opp).
      3. Velg «Legg til på Hjem-skjerm» og trykk Legg til.
